Privacy Policy

Last updated: 29 October 2026

Clipping Pipeline ("the app") is a personal automation tool used only by its owner. This policy explains how it handles Google user data.

Data the app accesses

  • YouTube: permission to upload videos to the owner's own channel and read view counts for those videos.
  • Google Drive: permission to read the owner's source-footage files, and to create, share by link, and delete temporary files the app itself creates so Instagram can fetch a clip.

How the data is used

Data is used only to run the app's features for the owner: publishing clips and tracking their performance. It is not used for advertising, analytics about other people, or any other purpose.

Storage and sharing

Sign-in tokens and app data are stored only on the owner's own computer. The app does not send Google user data to any server run by the developer, and does not sell, share, or transfer it to third parties. Temporary Drive files are deleted right after use.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
